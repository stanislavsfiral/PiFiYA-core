# PiFiYA (PiFiYA-core)

Квантово-оптическое и топологическое ядро на базе геометрии **Сфирали** (Sfiral), S-переходов и троичных фазовых расчетов.

## 🚀 О проекте
**PiFiYA** — это программный комплекс и архитектурная модель, объединяющая фундаментальные математические константы (\pi, \Fi) с принципами зеркально-антисимметричной топологии. Проект предназначен для моделирования волновых процессов, спектрального анализа (Фурье/Уолш) и управления многоуровневыми логическими структурами (кудитами).

## 🛠 Архитектура и возможности
- **Топология Сфирали:** Зеркально-антисимметричные витки с плавной инверсией хиральности через S-образный переход без разрыва потока.
- **Интерактивный конструктор:** Инструменты для визуализации и масштабирования фрактальных диполей и узлов (`core`, `editor`, `visualizer`).
- **Спектральный анализ:** Встроенный расчет фазовых гармоник и состояний системы в реальном времени.
- **Троичная логика:** Опора на сбалансированные фазовые состояния (`+1`, `0`, `-1`).

## 📁 Структура репозитория
- `core/` — математическое ядро и расчеты (включая троичные преобразования Уолша).
- `editor/` — логика редактора, конструктора и построения фракталов.
- `visualizer/` — движок рендеринга сцены и отображения волновых контуров.
- `модели/` — готовые JSON-файлы конфигураций и ядер (например, модели на 32 и 96 узлов).
- `constructor.html` / `index.html` — веб-интерфейс управления и визуализации.
