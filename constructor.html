1. Навигация в трехмерном пространстве (Камера и Виды)

Для удобного проектирования топологических схем Сфирали используются следующие элементы управления камерой:

Действие / Клавиша Назначение и эффект
Ctrl + Правая кнопка мыши (ПКМ) Вращение камеры по орбите вокруг центра сцены (в отличие от визуализатора, здесь задействован модификатор Ctrl во избежание конфликтов с выделением).
Колесо мыши (Зум) Приближение и отдаление точки обзора (масштабирование).
Переключатели вида (Перспектива / Сверху / Спереди / Сбоку) Расположены на панели инструментов. Позволяют мгновенно переключаться между проекциями для точного выравнивания узлов.

2. Выделение элементов и работа с группами

Интерфейс конструктора поддерживает два основных режима выбора элементов для дальнейшего редактирования:

Способ выбора Описание
ЛКМ (Левая кнопка мыши) + Протягивание Создает прямоугольную рамку выделения прямо на холсте. Все узлы и связи, попавшие внутрь рамки, объединяются в единую группу для массовой правки.
Shift + Клик Позволяет осуществлять точечный множественный выбор отдельных узлов, добавляя их к текущей группе.

3. Инструменты правой панели (Свойства, Фрактализация и Группы)

Правая боковая панель содержит блоки для индивидуальных свойств узлов, а также отдельные колонки/секции для работы с группами выделенных объектов:

Блок панели Параметры и функционал
Свойства и элементы Верхняя зона панели. Отображает детальную информацию и параметры выбранного в данный момент отдельного узла или элемента цепи.
Фрактализация по шаблону Поле Глубина (Level) (от 1 до 4) задает допустимый уровень вложенности. Кнопка «Запечь фрактальные диполи» автоматически генерирует разветвленные диполи на основе топологии Сфирали.
Плавное сжатие выделенного Позволяет плавно масштабировать выделенные объекты с шагом в 1%. Кнопка «Сжать -1%» уменьшает габариты сборки.
Целевая позиция центра (XYZ) Три числовых поля ввода (X, Y, Z) и кнопка «Переместить в точку». Служат для точного перемещения центра всей группы в заданные координаты пространства.
Поворот группы (°) Три поля ввода для углов (в градусах) по осям X, Y и Z. Кнопка «Применить» осуществляет вращение выделенной сборки элементов вокруг собственного центра.

4. Топологические основы Сфирали

• Зеркальная антисимметрия: Устройства состоят из левого и правого витков, обладающих разной хиральностью. В сборе система имеет нулевую хиральность целого.
• S-переход: Зона плавной ламинарной деформации, в которой происходит инверсия хиральности без разрыва потока сигнала.
